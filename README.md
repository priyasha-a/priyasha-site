# Priyasha Agarwal — personal site

My personal site: a single page with an about section, projects,
experience and contact links.

Built as plain HTML and CSS with no frameworks and no build step, so
`index.html` can be opened directly in a browser.

Hosted on Vercel, which redeploys automatically whenever this repository
changes.

## Files

| File | What it is |
|---|---|
| `index.html` | The whole site — content, styling and the one small script |
| `.gitignore` | Files that should never be published |

## Editing

Open `index.html` in any text editor. The sections marked `EDIT` near the
top of the file point to everything meant to be changed.
